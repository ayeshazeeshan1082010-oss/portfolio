Project Overview

Azure Grand Resort is a luxury hospitality website created to present the resort, rooms and suites, dining experience, and booking journey through a clean and premium digital interface. The website was built in WordPress using Elementor Pro with custom styling and responsive layouts.

Development

The website was developed in WordPress using Elementor Pro to build and arrange the page layouts. Custom CSS was used where needed to refine spacing, visual details, responsive behavior, and the premium hotel presentation. The design follows a navy, gold, and ivory visual system to maintain a sophisticated hospitality aesthetic.
